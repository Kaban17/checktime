# CheckTime

[English version](README.md)

Учёт времени на Android, при котором расписаны все 24 часа в сутки. Каждые N минут
поверх других приложений появляется окно, в котором прошедшее время делится между
категориями. Распределение можно отложить: нерасписанное время копится в один
хвост и раздаётся целиком при следующем показе, поэтому дыр в учёте не бывает.

Интерфейс на русском и английском, язык берётся из системы (на Android 13+ его
можно выбрать для приложения отдельно в настройках системы).

## Возможности

- **Окно распределения**: слайдер на каждую категорию. Ползунок прилипает к шагу
  из настроек и упирается в остаток. Тап по названию отдаёт категории весь остаток.
  Жест «назад» откладывает распределение.
- **День**: записи за день и итоги по категориям. Тап по записи открывает шторку,
  где можно сменить категорию, разбить запись, сдвинуть границу с соседней или
  слить их.
- **Статистика**: день, неделя, месяц или произвольный диапазон. Показывает
  таблицу «группа → категории» и диаграмму.
- **Цели**: недельный минимум на группу или категорию с полосой прогресса.
  Цель действует, пока её не изменят; прошлые недели сохраняют свои цели.
- **Настройки**: интервал, время откладывания, шаг слайдеров, редактор групп
  и категорий, чеклист разрешений.

Окно не будит экран. Будильник выставляет уведомление «Не расписано: X мин»,
а само окно открывается после разблокировки телефона.

## Разрешения

- «Поверх других приложений» обязательно, без него окно не появляется и
  остаётся только уведомление.
- Уведомления (Android 13+), точные будильники, отключение оптимизации батареи.

Все разрешения перечислены в чеклисте на экране настроек.

## Сборка

Требуются JDK 21 и Android SDK (compileSdk 37.2). minSdk 26, targetSdk 36.

```sh
./gradlew :app:assembleDebug        # сборка
./gradlew :app:installDebug         # установка на подключённый телефон
./gradlew :app:testDebugUnitTest    # тесты (Robolectric + Room в памяти)
```

Путь к JDK задан в `gradle.properties` (`org.gradle.java.home`). Если JDK лежит
в другом месте, поправьте этот путь. Путь к SDK задаётся в `local.properties`
(`sdk.dir=...`).
